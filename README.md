# Uday Sangu — Portfolio

## Run locally
1. Keep the `index.html`, `style.css`, `script.js`, and `assets/` folder together.
2. Open `index.html` in a browser. For a smoother development workflow, use VS Code + Live Server.

## Personalize before publishing
- In `index.html`, replace `your.email@example.com` with your email.
- Replace the generic LinkedIn and GitHub URLs with your profile URLs.
- Add verified GitHub/demo links and screenshots for each project.
- Confirm project descriptions and technologies match what you personally implemented.
- Update the status line if you are not currently available for opportunities.

The profile photo is stored at `assets/profile.png`.
